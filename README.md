## 🚀 গিটহাব পেজেস-এ প্রকাশের বাংলা নির্দেশিকা (GitHub Pages Deployment Guide)

এই প্রকল্পটি গিটহাব অ্যাকশনসের মাধ্যমে সরাসরি অটোমেটিক হোস্ট করার জন্য প্রস্তুত।

### ধাপ ১: গিট রিপোজিটরিতে কোড আপলোড করুন
```bash
git init
git add .
git commit -m "Initial commit for Maju Electrician Portfolio"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/maju-electrician.git
git push -u origin main
```

### ধাপ ২: গিটহাবে Pages অপশন সক্রিয় করুন
১. আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।  
২. বাম পাশের মেনু থেকে **Pages** নির্বাচন করুন।  
৩. **Build and deployment** সেকশনের অধীনে **Source** ড্রপডাউনে `GitHub Actions` নির্বাচন করুন।  
৪. এবার কোড পুশ করলেই `.github/workflows/deploy.yml` নিজে থেকে সাইট বিল্ড করে `https://আপনার-ইউজারনেম.github.io/maju-electrician/` লিংকে সাইটটি লাইভ করে দেবে।

## 🌐 নিজস্ব ডোমেইন যুক্ত করার বাংলা নির্দেশিকা (Custom Domain Setup Guide)

ভবিষ্যতে যখন আপনি নিজের ডোমেইন (যেমন: `majuelectrician.com`) কিনবেন, তখন নিচের পদক্ষেপগুলো অনুসরণ করবেন:

১. `public/CNAME` ফাইলে শুধুমাত্র আপনার ডোমেইন নামটি লিখুন (যেমন: `majuelectrician.com`)।  
২. আপনার ডোমেইন প্রোভাইডারের (Namecheap, GoDaddy ইত্যাদি) DNS ম্যানেজমেন্টে যান এবং নিচের রেকর্ডগুলো যুক্ত করুন:
   - **Type:** `A`  
     **Host:** `@`  
     **Value:** (গিটহাবের ৪টি আইপি অ্যাড্রেস)
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - **Type:** `CNAME`  
     **Host:** `www`  
     **Value:** `আপনার-ইউজারনেম.github.io`
৩. GitHub Settings > Pages-এ গিয়ে **Custom domain** ঘরে `majuelectrician.com` লিখে সেভ করুন এবং **Enforce HTTPS** টিক দিয়ে দিন। এতে আপনার সাইটে ফ্রি SSL সিকিউরিটি চালু হয়ে যাবে।

## 🔄 ভবিষ্যতে ছবি, সেবা ও গ্রাহকদের মতামত পরিবর্তনের নিয়ম

### ১. নতুন কাজের ছবি যুক্ত করা:
- নতুন কাজের ছবি তৈরি করে `public/assets/work/` ফোল্ডারে রাখুন (যেমন: `my_work.webp`)।
- `src/data/portfolio.ts` ফাইলের `GALLERY_DATA` অ্যারেতে নতুন একটি আইটেম যোগ করুন:
```typescript
{
  id: "g5",
  title: "আপনার নতুন কাজের শিরোনাম",
  category: "electrical", // electrical, sanitary অথবা pump
  categoryLabel: "বৈদ্যুতিক ওয়্যারিং",
  image: "assets/work/my_work.webp",
  description: "কাজের সংক্ষিপ্ত বিবরণ",
  isSample: false
}
```

### ২. সেবা তালিকায় পরিবর্তন:
- `src/data/portfolio.ts` এর `SERVICES_DATA` অংশে প্রয়োজন অনুযায়ী নতুন সেবার নাম যোগ বা পরিবর্তন করতে পারবেন।

### ৩. গ্রাহকদের বাস্তব মতামত যুক্ত করা:
- গ্রাহকের অনুমতি সাপেক্ষে `src/data/portfolio.ts` এ গ্রাহকের নাম, এলাকা ও বাস্তব মন্তব্য যুক্ত করে দিলে তা ওয়েবসাইটের রিভিউ বিভাগে দৃশ্যমান হবে।
